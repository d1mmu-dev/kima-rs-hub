# M0 Skeleton Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A runnable `kima` binary that connects to Postgres, runs migrations, has a working job queue, lets the first user register and log in with JWTs, streams server events over SSE, and serves the forked Kima frontend as a static export. All of it ships as one Docker image.

**Architecture:** A Cargo workspace with five crates in this milestone. `kima-core` holds config, secrets, password/JWT logic and the event bus, with no web or DB dependencies. `kima-db` holds sqlx migrations and queries. `kima-jobs` holds the Postgres job queue and worker. `kima-api` holds the axum handlers. `kima-server` holds the binary and serves the frontend. The frontend is upstream's Next.js app forked into `frontend/` and built with `output: "export"`.

**Tech Stack:** Rust (edition 2024), axum 0.8, sqlx 0.8 (Postgres), tokio, jsonwebtoken 9, argon2 0.5, tower-http 0.6, axum-test 17, Postgres 17 + pgvector, Next.js 16 (static export), Playwright.

## Global Constraints

- License `GPL-3.0-only` on every crate; edition `2024`; `rust-version = "1.85"`.
- Crate versions are pinned in the workspace `Cargo.toml` (Task 1). The code in this plan is written against those versions; upgrading them is a separate task.
- Domain crates (`kima-core`, `kima-db`, `kima-jobs`) never depend on axum.
- Environment variables keep upstream's names: `DATABASE_URL`, `MUSIC_PATH`, `PORT` (default `3030`), `LOG_LEVEL` (default `info`), `ALLOWED_ORIGINS`, `SESSION_SECRET`, `SETTINGS_ENCRYPTION_KEY`. New ones: `KIMA_DATA_DIR` (default `/data`), `KIMA_FRONTEND_DIR` (unset means no frontend), `KIMA_BIND_HOST` (default `0.0.0.0`).
- API JSON uses camelCase keys, and errors are `{"error": "<message>"}`, as upstream does.
- IDs are UUIDv7 (`Uuid::now_v7()`).
- The DB is never mocked. DB tests use `#[sqlx::test(migrator = "kima_db::MIGRATOR")]` against the dev Postgres from Task 1 (`DATABASE_URL` in `.env`).
- **Every difference from upstream gets a row in `docs/DIVERGENCES.md` in the same commit that introduces it** (next free ID, status `open` unless the task says otherwise).
- Commit messages: conventional style (`feat:`, `test:`, `docs:`, `chore:`), ending with the `Co-Authored-By` trailer the session provides.
- Before each commit that touches Rust: `cargo fmt --all` and `cargo clippy --workspace --all-targets -- -D warnings` must be clean.
- Test code calls axum-test 17 helpers (`authorization_bearer`, `add_header`, `assert_json`, `assert_text`, `header`, `maybe_header`, `text`, `content_type`). If one is named or typed differently in the resolved version, adapt the **call** to the equivalent helper and keep the assertion unchanged.
- After adding or changing any `sqlx::query!`/`query_as!`/`query_scalar!` macro: run `cargo sqlx prepare --workspace -- --all-targets` and commit the `.sqlx/` directory, because CI builds with `SQLX_OFFLINE=true`.

## Review Focus

1. Two people register at the same moment on a fresh install. Exactly one becomes admin, and the other is told registration is closed (test in Task 4).
2. A user's `token_version` is bumped (future password change or "log out everywhere"). Every old access and refresh token is rejected immediately (test in Task 8).
3. A browser closes its event stream. The per-user stream slot is freed, so the 6th tab gets 429 but works once another tab closes (test in Task 9).
4. `/data/secrets.json` is corrupt or unreadable. The server refuses to start and does **not** overwrite the file, because regenerating it would make stored encrypted settings unreadable (test in Task 2).
5. A worker dies mid-job. The job is reclaimed after its lease expires, and is not retried beyond `max_attempts` (tests in Tasks 5 and 6).

```rust
pub fn load_or_generate(
    data_dir: &Path,
    env_session: Option<String>,
    env_key: Option<String>,
) -> Result<Secrets, SecretsError> {
    let path = data_dir.join(SECRETS_FILE);
    let stored = match fs::read_to_string(&path) {
        Ok(text) => serde_json::from_str::<SecretsFile>(&text)
            .map_err(|source| SecretsError::Corrupt { path: path.clone(), source })?,
        Err(e) if e.kind() == io::ErrorKind::NotFound => {
            let fresh = SecretsFile {
                session_secret: random_secret(),
                settings_encryption_key: random_secret(),
            };
            let json = serde_json::to_string_pretty(&fresh).expect("secrets serialise");
            write_private(&path, &json)?;
            fresh
        }
        Err(source) => return Err(SecretsError::Io { path, source }),
    };
    Ok(Secrets {
        session_secret: env_session.unwrap_or(stored.session_secret),
        settings_encryption_key: env_key.unwrap_or(stored.settings_encryption_key),
    })
}

fn random_secret() -> String {
    let mut bytes = [0u8; 32];
    rand::rngs::OsRng.fill_bytes(&mut bytes);
    STANDARD.encode(bytes)
}

/// Writes through a temporary file so a crash never leaves a half-written secrets file.
fn write_private(path: &Path, contents: &str) -> Result<(), SecretsError> {
    let io_err = |source: io::Error| SecretsError::Io { path: path.to_path_buf(), source };
    if let Some(dir) = path.parent() {
        fs::create_dir_all(dir).map_err(io_err)?;
    }
    let tmp = path.with_extension("json.tmp");
    let mut options = fs::OpenOptions::new();
    options.write(true).create(true).truncate(true);
    #[cfg(unix)]
    {
        use std::os::unix::fs::OpenOptionsExt;
        options.mode(0o600);
    }
    let mut file = options.open(&tmp).map_err(io_err)?;
    file.write_all(contents.as_bytes()).map_err(io_err)?;
    file.sync_all().map_err(io_err)?;
    fs::rename(&tmp, path).map_err(io_err)
}
```

```rust
impl JwtKeys {
    pub fn new(secret: &str) -> Self {
        let mut validation = Validation::new(Algorithm::HS256);
        validation.leeway = 0;
        Self {
            encoding: EncodingKey::from_secret(secret.as_bytes()),
            decoding: DecodingKey::from_secret(secret.as_bytes()),
            validation,
        }
    }

    pub fn issue_access(&self, user_id: Uuid, username: &str, role: &str, token_version: i32) -> String {
        self.sign(
            Claims {
                user_id,
                username: Some(username.to_string()),
                role: Some(role.to_string()),
                token_version,
                token_type: None,
                scope: None,
                iat: 0,
                exp: 0,
            },
            ACCESS_TTL_SECS,
        )
    }

    pub fn issue_refresh(&self, user_id: Uuid, token_version: i32) -> String {
        self.sign(
            Claims {
                user_id,
                username: None,
                role: None,
                token_version,
                token_type: Some("refresh".into()),
                scope: None,
                iat: 0,
                exp: 0,
            },
            REFRESH_TTL_SECS,
        )
    }

    pub fn issue_stream(&self, user_id: Uuid, token_version: i32) -> String {
        self.sign(
            Claims {
                user_id,
                username: None,
                role: None,
                token_version,
                token_type: None,
                scope: Some("stream".into()),
                iat: 0,
                exp: 0,
            },
            STREAM_TTL_SECS,
        )
    }

    pub fn decode(&self, token: &str) -> Result<Claims, InvalidToken> {
        decode::<Claims>(token, &self.decoding, &self.validation)
            .map(|data| data.claims)
            .map_err(|_| InvalidToken)
    }

    /// Stamps `iat`/`exp` (now, now + `ttl_secs`) and signs.
    fn sign(&self, mut claims: Claims, ttl_secs: i64) -> String {
        let now = time::OffsetDateTime::now_utc().unix_timestamp();
        claims.iat = now;
        claims.exp = now + ttl_secs;
        encode(&Header::new(Algorithm::HS256), &claims, &self.encoding)
            .expect("HS256 signing cannot fail")
    }
}
```

```rust
use sqlx::PgPool;
use time::OffsetDateTime;
use uuid::Uuid;

pub const ROLE_ADMIN: &str = "admin";
pub const ROLE_USER: &str = "user";

/// Advisory lock key that serialises registrations ("kima" in ASCII, then 1).
const REGISTRATION_LOCK: i64 = 0x6b69_6d61_0000_0001;

#[derive(Debug, Clone, PartialEq)]
pub struct User {
    pub id: Uuid,
    pub username: String,
    pub password_hash: String,
    pub role: String,
    pub onboarding_complete: bool,
    pub token_version: i32,
    pub created_at: OffsetDateTime,
}

#[derive(Debug)]
pub enum Registration {
    Created(User),
    Closed,
    UsernameTaken,
}

/// Creates a user. The first user becomes admin; later ones need registration to be open.
pub async fn register(
    pool: &PgPool,
    id: Uuid,
    username: &str,
    password_hash: &str,
) -> sqlx::Result<Registration> {
    let mut tx = pool.begin().await?;
    // Two simultaneous first sign-ups would otherwise both see zero users and both become admin.
    sqlx::query("SELECT pg_advisory_xact_lock($1)")
        .bind(REGISTRATION_LOCK)
        .execute(&mut *tx)
        .await?;

    let existing = sqlx::query_scalar!(r#"SELECT count(*) AS "count!" FROM users"#)
        .fetch_one(&mut *tx)
        .await?;
    if existing > 0 {
        let open = sqlx::query_scalar!("SELECT registration_open FROM system_settings")
            .fetch_one(&mut *tx)
            .await?;
        if !open {
            return Ok(Registration::Closed);
        }
        let taken = sqlx::query_scalar!(
            r#"SELECT EXISTS (SELECT 1 FROM users WHERE lower(username) = lower($1)) AS "taken!""#,
            username
        )
        .fetch_one(&mut *tx)
        .await?;
        if taken {
            return Ok(Registration::UsernameTaken);
        }
    }

    let role = if existing == 0 { ROLE_ADMIN } else { ROLE_USER };
    let user = sqlx::query_as!(
        User,
        r#"INSERT INTO users (id, username, password_hash, role)
           VALUES ($1, $2, $3, $4)
           RETURNING id, username, password_hash, role, onboarding_complete, token_version, created_at"#,
        id,
        username,
        password_hash,
        role
    )
    .fetch_one(&mut *tx)
    .await?;
    tx.commit().await?;
    Ok(Registration::Created(user))
}

pub async fn find_by_username(pool: &PgPool, username: &str) -> sqlx::Result<Option<User>> {
    sqlx::query_as!(
        User,
        r#"SELECT id, username, password_hash, role, onboarding_complete, token_version, created_at
           FROM users WHERE lower(username) = lower($1)"#,
        username
    )
    .fetch_optional(pool)
    .await
}

    sqlx::query_as!(
        User,
        r#"SELECT id, username, password_hash, role, onboarding_complete, token_version, created_at
           FROM users WHERE id = $1"#,
        id
    )
    .fetch_optional(pool)
    .await
}

pub async fn count(pool: &PgPool) -> sqlx::Result<i64> {

        .fetch_one(pool)
        .await
}

}

pub async fn set_onboarding_complete(pool: &PgPool, id: Uuid) -> sqlx::Result<()> {
```

```rust
use std::time::Duration;

use sqlx::PgPool;
use uuid::Uuid;

pub const NOTIFY_CHANNEL: &str = "kima_jobs";

#[derive(Debug, Clone, PartialEq)]
pub struct Job {
    pub id: Uuid,
    pub queue: String,
    pub payload: serde_json::Value,
    pub attempts: i32,
    pub max_attempts: i32,
}

/// Adds a job and wakes the workers listening on [`NOTIFY_CHANNEL`] (on commit).
pub async fn enqueue(
    pool: &PgPool,
    queue: &str,
    payload: serde_json::Value,
    max_attempts: i32,
) -> sqlx::Result<Uuid> {
    let id = Uuid::now_v7();
    let mut tx = pool.begin().await?;
    sqlx::query!(
        "INSERT INTO jobs (id, queue, payload, max_attempts) VALUES ($1, $2, $3, $4)",
        id,
        queue,
        payload,
        max_attempts
    )
    .execute(&mut *tx)
    .await?;
    sqlx::query("SELECT pg_notify($1, $2)")
        .bind(NOTIFY_CHANNEL)
        .bind(queue)
        .execute(&mut *tx)
        .await?;
    tx.commit().await?;
    Ok(id)
}

/// Takes up to `limit` due jobs, including ones whose worker's lease ran out.
pub async fn claim(pool: &PgPool, queue: &str, limit: i64, lease: Duration) -> sqlx::Result<Vec<Job>> {
    sqlx::query_as!(
        Job,
        r#"UPDATE jobs
           SET state = 'running',
               attempts = attempts + 1,
               locked_until = now() + make_interval(secs => $3)
           WHERE id IN (
               SELECT id FROM jobs
               WHERE queue = $1
                 AND ((state = 'queued' AND run_at <= now())
                      OR (state = 'running' AND locked_until < now() AND attempts < max_attempts))
               ORDER BY run_at, id
               LIMIT $2
               FOR UPDATE SKIP LOCKED)
           RETURNING id, queue, payload, attempts, max_attempts"#,
        queue,
        limit,
        lease.as_secs_f64()
    )
    .fetch_all(pool)
    .await
}

pub async fn complete(pool: &PgPool, id: Uuid) -> sqlx::Result<()> {
    sqlx::query!(
        "UPDATE jobs SET state = 'done', locked_until = NULL, last_error = NULL, finished_at = now()
         WHERE id = $1",
        id
    )
    .execute(pool)
    .await?;
    Ok(())
}

/// Records a failed attempt: retried after [`backoff`], or failed for good on the last attempt.
pub async fn fail(pool: &PgPool, job: &Job, error: &str) -> sqlx::Result<()> {
    if job.attempts >= job.max_attempts {
        sqlx::query!(
            "UPDATE jobs SET state = 'failed', locked_until = NULL, last_error = $2, finished_at = now()
             WHERE id = $1",
            job.id,
            error
        )
        .execute(pool)
        .await?;
    } else {
        sqlx::query!(
            "UPDATE jobs SET state = 'queued', locked_until = NULL, last_error = $2,
                             run_at = now() + make_interval(secs => $3)
             WHERE id = $1",
            job.id,
            error,
            backoff(job.attempts).as_secs_f64()
        )
        .execute(pool)
        .await?;
    }
    Ok(())
}

/// Fails jobs whose lease ran out on their final attempt (their worker died).
pub async fn reap(pool: &PgPool) -> sqlx::Result<u64> {
    let result = sqlx::query!(
        "UPDATE jobs SET state = 'failed', locked_until = NULL, finished_at = now(),
                         last_error = 'lease expired on the final attempt'
         WHERE state = 'running' AND locked_until < now() AND attempts >= max_attempts"
    )
    .execute(pool)
    .await?;
    Ok(result.rows_affected())
}

/// Delay before retrying after attempt `attempts`: 5 s, 10 s, 20 s, ... at most 1 h.
pub fn backoff(attempts: i32) -> Duration {
    let exponent = (attempts.max(1) - 1).min(20) as u32;
    Duration::from_secs(5u64.saturating_mul(1 << exponent).min(3600))
}
```

```rust
use std::panic::AssertUnwindSafe;

use futures::FutureExt;
use sqlx::postgres::PgListener;
use tokio::sync::Semaphore;
use tokio::task::JoinSet;
use tracing::warn;

use crate::queue::{self, NOTIFY_CHANNEL};

/// Runs `handler` for jobs on `config.queue`, at most `config.concurrency` at a time,
/// until `shutdown` fires; then waits for jobs already running.
pub fn spawn_worker(
    pool: PgPool,
    config: WorkerConfig,
    handler: Handler,
    shutdown: CancellationToken,
) -> JoinHandle<()> {
    tokio::spawn(async move {
        let mut listener = listen(&pool).await;
        let permits = Arc::new(Semaphore::new(config.concurrency));
        let mut running = JoinSet::new();

        while !shutdown.is_cancelled() {
            while running.try_join_next().is_some() {}
            if let Err(error) = queue::reap(&pool).await {
                warn!(%error, "reaping expired jobs failed");
            }

            let free = permits.available_permits();
            if free > 0 {
                match queue::claim(&pool, &config.queue, free as i64, config.lease).await {
                    Ok(jobs) => {
                        let claimed_all = jobs.len() == free;
                        for job in jobs {
                            let permit = permits.clone().acquire_owned().await.expect("never closed");
                            let (pool, handler) = (pool.clone(), handler.clone());
                            running.spawn(async move {
                                run_one(&pool, &handler, job).await;
                                drop(permit);
                            });
                        }
                        if claimed_all {
                            continue; // the queue may hold more; claim again once a slot frees
                        }
                    }
                    Err(error) => warn!(%error, queue = %config.queue, "claiming jobs failed"),
                }
            }

            tokio::select! {
                _ = shutdown.cancelled() => break,
                _ = notified(&mut listener) => {}
                Some(_) = running.join_next(), if !running.is_empty() => {}
                _ = tokio::time::sleep(config.poll_interval) => {}
            }
        }

        while running.join_next().await.is_some() {}
    })
}

async fn listen(pool: &PgPool) -> Option<PgListener> {
    let mut listener = match PgListener::connect_with(pool).await {
        Ok(listener) => listener,
        Err(error) => {
            warn!(%error, "LISTEN unavailable; falling back to polling");
            return None;
        }
    };
    match listener.listen(NOTIFY_CHANNEL).await {
        Ok(()) => Some(listener),
        Err(error) => {
            warn!(%error, "LISTEN failed; falling back to polling");
            None
        }
    }
}

async fn notified(listener: &mut Option<PgListener>) {
    match listener {
        Some(l) => {
            if let Err(error) = l.recv().await {
                warn!(%error, "job notification stream failed");
                tokio::time::sleep(Duration::from_secs(1)).await;
            }
        }
        None => std::future::pending().await,
    }
}

async fn run_one(pool: &PgPool, handler: &Handler, job: Job) {
    let outcome = AssertUnwindSafe(handler(job.clone())).catch_unwind().await;
    let recorded = match outcome {
        Ok(Ok(())) => queue::complete(pool, job.id).await,
        Ok(Err(message)) => queue::fail(pool, &job, &message).await,
        Err(_) => queue::fail(pool, &job, "handler panicked").await,
    };
    if let Err(error) = recorded {
        warn!(%error, job = %job.id, "could not record job outcome");
    }
}
```

When the busy-loop `continue` runs with every permit taken, the next iteration has `free == 0` and falls through to the `select!`, which wakes when a running job finishes. So the loop doesn't spin.

```rust
use axum::Json;
use axum::http::StatusCode;
use axum::response::{IntoResponse, Response};
use serde_json::json;

#[derive(Debug, thiserror::Error)]
pub enum ApiError {
    /// 400 `{"error":"Invalid request","details":...}`: the body failed validation.
    #[error("Invalid request")]
    Invalid(String),
    #[error("{0}")]
    BadRequest(String),
    #[error("{0}")]
    Unauthorized(&'static str),
    #[error("{0}")]
    Forbidden(&'static str),
    #[error("{0}")]
    NotFound(&'static str),
    #[error("{0}")]
    TooManyRequests(&'static str),
    #[error("Internal error")]
    Internal(#[from] anyhow::Error),
}

impl From<sqlx::Error> for ApiError {
    fn from(error: sqlx::Error) -> Self {
        Self::Internal(error.into())
    }
}

impl IntoResponse for ApiError {
    fn into_response(self) -> Response {
        let status = match &self {
            Self::Invalid(_) | Self::BadRequest(_) => StatusCode::BAD_REQUEST,
            Self::Unauthorized(_) => StatusCode::UNAUTHORIZED,
            Self::Forbidden(_) => StatusCode::FORBIDDEN,
            Self::NotFound(_) => StatusCode::NOT_FOUND,
            Self::TooManyRequests(_) => StatusCode::TOO_MANY_REQUESTS,
            Self::Internal(error) => {
                tracing::error!(error = ?error, "internal error");
                StatusCode::INTERNAL_SERVER_ERROR
            }
        };
        let body = match &self {
            Self::Invalid(details) => json!({ "error": self.to_string(), "details": details }),
            _ => json!({ "error": self.to_string() }),
        };
        (status, Json(body)).into_response()
    }
}
```

```rust
use crate::error::ApiError;

/// `Json<T>` that answers malformed bodies with the API's JSON 400 instead of axum's plain text.
pub struct ApiJson<T>(pub T);

impl<S, T> FromRequest<S> for ApiJson<T>
where
    S: Send + Sync,
    T: DeserializeOwned,
{
    type Rejection = ApiError;

    async fn from_request(req: Request, state: &S) -> Result<Self, ApiError> {
        Json::<T>::from_request(req, state)
            .await
            .map(|Json(value)| ApiJson(value))
            .map_err(|rejection| ApiError::Invalid(rejection.body_text()))
    }
}
```

```rust
pub fn bearer_token(headers: &HeaderMap) -> Option<&str> {
    headers
        .get(AUTHORIZATION)?
        .to_str()
        .ok()?
        .strip_prefix("Bearer ")
        .map(str::trim)
        .filter(|token| !token.is_empty())
}

pub async fn authenticate(state: &AppState, token: &str, path: &str) -> Result<Option<AuthUser>, ApiError> {
    let Ok(claims) = state.jwt.decode(token) else {
        return Ok(None);
    };
    match claims.kind() {
        TokenKind::Refresh => return Ok(None),
        TokenKind::Stream if !path.ends_with("/stream") => return Ok(None),
        TokenKind::Access | TokenKind::Stream => {}
    }
    let Some(user) = users::find_by_id(&state.pool, claims.user_id).await? else {
        return Ok(None);
    };
    if user.token_version != claims.token_version {
        return Ok(None);
    }
    Ok(Some(AuthUser { id: user.id, username: user.username, role: user.role }))
}
```

```rust
async fn status(State(state): State<AppState>, headers: HeaderMap) -> Result<Json<Value>, ApiError> {

    let registration_open = !has_account || users::registration_open(&state.pool).await?;

        Some(token) => authenticate(&state, token, "/api/onboarding/status").await?,

            .await?
            .is_some_and(|u| u.onboarding_complete),

        "hasAccount": has_account,
        "registrationOpen": registration_open,

async fn register(
    State(state): State<AppState>,
    ApiJson(body): ApiJson<Credentials>,
) -> Result<Json<Value>, ApiError> {

        return Err(ApiError::Invalid("Username must be 3 to 50 characters".into()));

        return Err(ApiError::Invalid("Password must be at least 6 characters".into()));
```

```rust
//! In-process publish/subscribe for server-sent events (replaces upstream's Redis pub/sub).

use tokio::sync::broadcast;
use uuid::Uuid;

#[derive(Debug, Clone, PartialEq)]
pub struct Event {
    /// `None` reaches every user.
    pub user_id: Option<Uuid>,
    pub data: serde_json::Value,
}

impl Event {
    pub fn is_for(&self, user: Uuid) -> bool {
        self.user_id.is_none_or(|id| id == user)
    }
}

#[derive(Clone)]
pub struct EventBus {
    tx: broadcast::Sender<Event>,
}

impl EventBus {
    pub fn new(capacity: usize) -> Self {
        Self { tx: broadcast::channel(capacity).0 }
    }

    /// Sends to current subscribers; with none listening the event is dropped.
    pub fn publish(&self, event: Event) {
        let _ = self.tx.send(event);
    }

    pub fn subscribe(&self) -> broadcast::Receiver<Event> {
        self.tx.subscribe()
    }
}
```

```rust
    pub fn issue_ticket(&self, user: Uuid) -> String {
        let ticket = Uuid::new_v4().simple().to_string();
        let now = Instant::now();
        let mut tickets = self.tickets.lock().unwrap();
        tickets.retain(|_, (_, issued)| now.duration_since(*issued) < self.ttl);
        tickets.insert(ticket.clone(), (user, now));
        ticket
    }

    pub fn redeem_ticket(&self, ticket: &str) -> Option<Uuid> {
        let (user, issued) = self.tickets.lock().unwrap().remove(ticket)?;
        (issued.elapsed() < self.ttl).then_some(user)
    }

        let mut open = self.open.lock().unwrap();

            return None;
        }
        *count += 1;
        Some(StreamSlot { registry: Arc::clone(self), user })
    }
```

```rust
#[derive(Deserialize)]
struct StreamQuery {
    ticket: Option<String>,
}

async fn stream(State(state): State<AppState>, Query(query): Query<StreamQuery>) -> Result<Response, ApiError> {
    let ticket = query.ticket.ok_or(ApiError::Unauthorized("Unauthorized"))?;
    let user = state
        .sse
        .redeem_ticket(&ticket)
        .ok_or(ApiError::Unauthorized("Invalid or expired ticket"))?;
    let slot = state
        .sse
        .try_open(user)
        .ok_or(ApiError::TooManyRequests("Too many event streams open"))?;

    let connected = futures::stream::once(async {
        Ok::<_, Infallible>(SseEvent::default().data(r#"{"type":"connected"}"#))
    });
    // A lagging client skips what it missed rather than being disconnected.
    let events = BroadcastStream::new(state.events.subscribe()).filter_map(move |message| {
        let event = match message {
            Ok(event) if event.is_for(user) => Some(Ok(SseEvent::default().data(event.data.to_string()))),
            _ => None,
        };
        std::future::ready(event)
    });
    // The slot lives as long as the stream; the client hanging up drops both.
    let stream = connected.chain(events).map(move |item| {
        let _held = &slot;
        item
    });

    let sse = Sse::new(stream).keep_alive(KeepAlive::new().interval(Duration::from_secs(30)).text("heartbeat"));
    Ok(([("x-accel-buffering", "no")], sse).into_response())
}
```

```rust
//! The exported Next.js app, plus redirects from upstream's path-style page URLs (D-011).

use std::path::Path;

use axum::Router;
use axum::extract::Path as UrlPath;
use axum::response::Redirect;
use axum::routing::get;
use tower_http::services::{ServeDir, ServeFile};

/// (old route, new page, query parameter name)
pub const LEGACY_ROUTES: &[(&str, &str, &str)] = &[
    ("/album/{value}", "/album/", "id"),
    ("/artist/{value}", "/artist/", "id"),
    ("/playlist/{value}", "/playlist/", "id"),
    ("/mix/{value}", "/mix/", "id"),
    ("/podcasts/{value}", "/podcasts/show/", "id"),
    ("/podcasts/genre/{value}", "/podcasts/genre/", "genreId"),
    ("/audiobooks/{value}", "/audiobooks/book/", "id"),
    ("/audiobooks/series/{value}", "/audiobooks/series/", "name"),
    ("/browse/playlists/{value}", "/browse/playlists/view/", "id"),
    ("/share/{value}", "/share/", "token"),
];

/// Fixed redirects that upstream's Next.js config or pages performed.
const FIXED_REDIRECTS: &[(&str, &str)] = &[
    ("/library", "/collection/"),
    ("/setup", "/login/"),
    ("/import/spotify", "/import/playlist/"),
];

/// New page directories that sit where a legacy `{value}` would match.
const PAGE_DIRS: &[&str] = &[
    "/podcasts/show",
    "/podcasts/genre",
    "/audiobooks/book",
    "/audiobooks/series",
    "/browse/playlists/view",
];

pub fn routes(dir: &Path) -> Router {
    let files = ServeDir::new(dir)
        .append_index_html_on_directories(true)
        .not_found_service(ServeFile::new(dir.join("404.html")));

    let mut router = Router::new();
    for &(route, page, param) in LEGACY_ROUTES {
        router = router.route(
            route,
            get(move |UrlPath(value): UrlPath<String>| async move {
                let encoded: String = form_urlencoded::byte_serialize(value.as_bytes()).collect();
                Redirect::permanent(&format!("{page}?{param}={encoded}"))
            }),
        );
    }
    for &(from, to) in FIXED_REDIRECTS {
        router = router.route(from, get(move || async move { Redirect::permanent(to) }));
    }
    for &page_dir in PAGE_DIRS {
        router = router.route_service(page_dir, files.clone());
    }
    router.fallback_service(files)
}
```

`ServeDir` answers a 404 through `not_found_service` with status 200 by default in some tower-http versions. If `unknown_page_gets_the_404_page` reports 200, wrap the service: `.not_found_service(tower_http::set_status::SetStatus::new(ServeFile::new(dir.join("404.html")), StatusCode::NOT_FOUND))`, adding `"set-status"` to the tower-http features in the workspace `Cargo.toml`.

```rust
//! Assembles the API, the static frontend and the cross-cutting HTTP layers.

use axum::Router;
use axum::http::{HeaderName, HeaderValue};
use kima_api::AppState;
use kima_core::config::Config;
use tower_http::cors::{AllowOrigin, Any, CorsLayer};
use tower_http::set_header::SetResponseHeaderLayer;
use tower_http::trace::TraceLayer;

pub mod frontend;

/// Upstream's Next.js `headers()` block, now applied by the server to every response.
const SECURITY_HEADERS: &[(&str, &str)] = &[
    ("permissions-policy", "camera=(), microphone=(), geolocation=()"),
    ("x-frame-options", "DENY"),
    ("x-content-type-options", "nosniff"),
    ("referrer-policy", "strict-origin-when-cross-origin"),
    ("x-dns-prefetch-control", "on"),
    (
        "content-security-policy",
        "default-src 'self'; script-src 'self' 'unsafe-inline' 'unsafe-eval'; style-src 'self' 'unsafe-inline'; \
         img-src 'self' data: blob: https://cdn-images.dzcdn.net https://e-cdns-images.dzcdn.net \
         https://assets.pippa.io https://is1-ssl.mzstatic.com; media-src 'self' blob:; \
         connect-src 'self' ws: wss:; font-src 'self'; frame-ancestors 'none'; worker-src 'self' blob:",
    ),
];

pub fn app(state: AppState, config: &Config) -> Router {
    let mut app = kima_api::router(state);
    if let Some(dir) = &config.frontend_dir {
        app = app.merge(frontend::routes(dir));
    }
    for &(name, value) in SECURITY_HEADERS {
        app = app.layer(SetResponseHeaderLayer::if_not_present(
            HeaderName::from_static(name),
            HeaderValue::from_static(value),
        ));
    }
    app.layer(cors(&config.allowed_origins)).layer(TraceLayer::new_for_http())
}

/// Unset `ALLOWED_ORIGINS` allows any origin, as upstream does.
fn cors(origins: &[String]) -> CorsLayer {
    let layer = CorsLayer::new().allow_methods(Any).allow_headers(Any);
    if origins.is_empty() {
        return layer.allow_origin(Any);
    }
    let list: Vec<HeaderValue> = origins.iter().filter_map(|o| HeaderValue::from_str(o).ok()).collect();
    layer.allow_origin(AllowOrigin::list(list))
}
```

```rust
use anyhow::Context;
use kima_api::AppState;
use kima_core::config::Config;
use kima_core::secrets;
use tokio::net::TcpListener;
use tracing::info;
use tracing_subscriber::EnvFilter;

#[tokio::main]
async fn main() -> anyhow::Result<()> {
    let config = Config::from_env()?;
    tracing_subscriber::fmt()
        .with_env_filter(EnvFilter::new(format!("{},tower_http=info", config.log_level)))
        .init();

    let secrets = secrets::load_or_generate(
        &config.data_dir,
        config.session_secret.clone(),
        config.settings_encryption_key.clone(),
    )?;
    let pool = kima_db::connect(&config.database_url).await.context("connecting to Postgres")?;
    kima_db::MIGRATOR.run(&pool).await.context("running migrations")?;

    let app = kima_server::app(AppState::new(pool, &secrets.session_secret), &config);
    let listener = TcpListener::bind(config.bind_addr)
        .await
        .with_context(|| format!("binding {}", config.bind_addr))?;
    info!(addr = %config.bind_addr, frontend = ?config.frontend_dir, "kima listening");
    axum::serve(listener, app).with_graceful_shutdown(shutdown_signal()).await?;
    Ok(())
}

async fn shutdown_signal() {
    let ctrl_c = async {
        let _ = tokio::signal::ctrl_c().await;
    };
    #[cfg(unix)]
    let terminate = async {
        tokio::signal::unix::signal(tokio::signal::unix::SignalKind::terminate())
            .expect("SIGTERM handler")
            .recv()
            .await;
    };
    #[cfg(not(unix))]
    let terminate = std::future::pending::<()>();
    tokio::select! {
        _ = ctrl_c => {},
        _ = terminate => {},
    }
    info!("shutting down");
}
```

```js
// One-off (D-011): rewrite template-literal page links from /album/${id} to /album/?id=${...}.
// Usage: node tools/frontend-route-codemod.mjs frontend
import { readFileSync, writeFileSync, readdirSync, statSync } from "node:fs";
import { join, relative } from "node:path";

const RULES = [
    ["/podcasts/genre/", "/podcasts/genre/?genreId="],
    ["/audiobooks/series/", "/audiobooks/series/?name="],
    ["/browse/playlists/", "/browse/playlists/view/?id="],
    ["/podcasts/", "/podcasts/show/?id="],
    ["/audiobooks/", "/audiobooks/book/?id="],
    ["/album/", "/album/?id="],
    ["/artist/", "/artist/?id="],
    ["/playlist/", "/playlist/?id="],
    ["/mix/", "/mix/?id="],
    ["/share/", "/share/?token="],
];
// API paths, not page links.
const SKIP = new Set(["lib/api.ts"]);

function* files(dir) {
    for (const name of readdirSync(dir)) {
        if (name === "node_modules" || name === ".next" || name === "out") continue;
        const path = join(dir, name);
        if (statSync(path).isDirectory()) yield* files(path);
        else if (/\.(ts|tsx)$/.test(name)) yield path;
    }
}

function rewrite(text) {
    const re = /`(\/[A-Za-z/]+\/)\$\{/g;
    let out = "";
    let last = 0;
    let m;
    while ((m = re.exec(text))) {
        const rule = RULES.find(([from]) => from === m[1]);
        if (!rule) continue;
        const exprStart = m.index + m[0].length;
        let depth = 1;
        let j = exprStart;
        while (depth > 0) {
            if (j >= text.length) throw new Error("unbalanced ${ at " + m.index);
            const c = text[j++];
            if (c === "{") depth++;
            else if (c === "}") depth--;
        }
        const expr = text.slice(exprStart, j - 1);
        const value = expr.startsWith("encodeURIComponent(") ? expr : `encodeURIComponent(${expr})`;
        out += text.slice(last, m.index) + "`" + rule[1] + "${" + value + "}";
        last = j;
        re.lastIndex = j;
    }
    return out + text.slice(last);
}

const root = process.argv[2];
for (const path of files(root)) {
    const rel = relative(root, path);
    if (SKIP.has(rel)) continue;
    const before = readFileSync(path, "utf8");
    const after = rewrite(before);
    if (after !== before) {
        writeFileSync(path, after);
        console.log("rewrote", rel);
    }
}
```

`docker/entrypoint.sh`:
```sh
#!/bin/bash
# Starts the bundled Postgres (unless DATABASE_URL points elsewhere), then kima; stops both cleanly.
set -euo pipefail

PGDATA=/data/postgres
mkdir -p /data
chown kima:kima /data

if [ -z "${DATABASE_URL:-}" ]; then
    mkdir -p "$PGDATA"
    chown -R postgres:postgres "$PGDATA"
    chmod 700 "$PGDATA"
    if [ ! -s "$PGDATA/PG_VERSION" ]; then
        gosu postgres initdb -D "$PGDATA" --username=kima --auth=trust --encoding=UTF8 >/dev/null
        echo "listen_addresses = '127.0.0.1'" >> "$PGDATA/postgresql.conf"
    fi
    gosu postgres pg_ctl -D "$PGDATA" -w -l "$PGDATA/server.log" start
    gosu postgres psql -h 127.0.0.1 -U kima -d postgres -tc "SELECT 1 FROM pg_database WHERE datname = 'kima'" \
        | grep -q 1 || gosu postgres createdb -h 127.0.0.1 -U kima kima
    export DATABASE_URL="postgres://kima@127.0.0.1:5432/kima"
    BUNDLED_PG=1
fi

stop_pg() {
    if [ "${BUNDLED_PG:-}" = 1 ]; then gosu postgres pg_ctl -D "$PGDATA" -m fast stop || true; fi
}

gosu kima kima &
KIMA_PID=$!
trap 'kill -TERM "$KIMA_PID" 2>/dev/null || true' TERM INT
set +e
wait "$KIMA_PID"; status=$?
# `wait` returns early when a trapped signal arrives; wait again for kima to finish.
if kill -0 "$KIMA_PID" 2>/dev/null; then wait "$KIMA_PID"; status=$?; fi
set -e
stop_pg
exit "$status"
```
